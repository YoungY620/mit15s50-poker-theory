# 术语表

收录本书出现的专业概念，按拼音分组。正文中的术语在桌面端悬浮、移动端点按可显示简介，点击可跳回本页对应条目。


## A

<a id="akqyouxi"></a>
**A-K-Q 游戏（Ace-King-Queen game）**　
双方各发一张 A/K/Q 的经典不完全信息玩具游戏。

双方各下前注、各发一张牌，玩家 1 可过牌或下注，玩家 2 只能过牌/跟注或弃牌。最优解：拿 A 必下注、对手下注拿 A 必跟、拿 Q 必弃；拿 K 下注是劣策略；应用全部 A 加 1/3 的 K 抓诈， 用最差的牌（Q）诈唬。它揭示的结构是：把牌分为价值牌、抓诈牌、诈唬牌三类，你对一手牌的 策略决定了对其他牌的策略。

*首次讲解：[L8 决策制定](ch08-decisions.html)*

<a id="af"></a>
**AF**　见 [激进系数（AF）](#jijinxishuaf)。

<a id="ansantiaowakuang"></a>
**暗三条挖矿（set mining）**　
翻牌前用口袋对子便宜地平跟，希望翻牌击中隐蔽的暗三条。

M > 30 时进入暗三条挖矿区（Set Mining Zone）：耐心等待怪兽牌，做成后猛烈地价值下注；便宜 地看翻牌，用底池赔率评估追坚果牌的听牌，隐含赔率要保守估计；如果你的牌不是绝对最大的可能 牌型，不要为 50M 打光。

*首次讲解：[L5 锦标赛打法](ch05-tournament.html)*


## B

<a id="bb100"></a>
**BB/100（BB/100）**　
线上现金局每百手赢的大盲注数，赢家的量化口径之一。

扑克中的“赢家”必须用量化指标定义：现金局（线上）以每百手赢的大盲注数 BB/100 计，优秀水准 为 5 BB/100；现金局（现场）以每小时赢的大盲注数计，优秀水准为 5 BB/小时。

*首次讲解：[L1 扑克理论导论](ch01-intro.html)*

<a id="banzhahu"></a>
**半诈唬（semi-bluff）**　
弃牌权益为负、靠摊牌胜率补偿后仍为 +EV 的下注。

半诈唬（semi-bluffing）兼具偷池和反超两条获胜路径，在锦标赛中极为常用——你不会总有成牌， 但总有能变成成牌的牌。速算规则：保本弃牌率 ≈ 纯诈唬保本弃牌率 − 摊牌胜率×1.5，该系数 总落在 (1, 2) 内。翻牌前的下注几乎总是半诈唬，翻牌前的全下本质上也是半诈唬。

*首次讲解：[L3 基本策略](ch03-basic-strategy.html)*

<a id="boxuedafa"></a>
**剥削打法（exploitive play）**　
在平衡的地基上按对手倾向移动边际的调整。

剥削打法是在平衡地基上根据对手倾向做的调整，原则是移动边际——只调整期望接近零的边际牌， 绝不动核心区域：对手诈唬太多就扩张边际跟注，弃牌太多就扩张边际诈唬。阅读的可信度决定边际 移动幅度；无论你对自己的阅读多有信心，你多半都高估了它。

*首次讲解：[L8 决策制定](ch08-decisions.html)*

<a id="boyilunzuiyou"></a>
**博弈论最优（game theory optimal (GTO)）**　
两人零和博弈中的纳什均衡，保证自己永不被剥削。

在两人零和博弈中，纳什均衡也称为博弈论最优（GTO），同时是最小最大解：在对手能看到你的 策略并作出最佳回应的前提下，这是你能做到的最好结果。GTO 不一定是“最好”的打法——即使在 单挑中，剥削对手的偏离往往收益更高；它的价值是保证自己永不被剥削。

*首次讲解：[L7 博弈论](ch07-game-theory.html)*

<a id="bupai"></a>
**补牌（outs）**　
发出后能让你获胜的剩余牌。

补牌（outs）是能让你获胜的牌，胜率由补牌数决定：9 张剩余红心做成同花的精确胜率约 34%。 补牌还可以按击中后赢的概率折算成“部分补牌”——若按保守估计结论仍是跟注，那实际更要跟。

*首次讲解：[L3 基本策略](ch03-basic-strategy.html)*


## C

<a id="cfr"></a>
**CFR**　见 [反事实后悔](#fanshishihouhui)。

<a id="cevyuev"></a>
**cEV 与 \\$EV（cEV and \\$EV）**　
筹码期望与金钱期望；锦标赛中二者方向一致但不严格相等。

现金局中每个筹码都有确定的货币价值，cEV = \\$EV；锦标赛中 cEV ≈ \\$EV，某些场合正 cEV 的 决策可能是负 \\$EV。极端情形如卫星赛：KK 对任意两张牌的跟注 ΔcEV = +1600 大赚，Δ\\$EV 却是 −\\$800，应该弃牌。

*首次讲解：[L5 锦标赛打法](ch05-tournament.html)*

<a id="chengpai"></a>
**成牌（made hand）**　
已经成型的牌力，如一对或两对。

翻牌圈最典型的局面是“弱成牌对听牌”（made hand vs drawing hand）。成牌方希望下注足够大， 使听牌方的跟注不是 +EV，也可以下一个差玩家会误以为是好价格的数目。任何不如“顶对好踢脚” 的成牌都应按听牌处理。

*首次讲解：[L3 基本策略](ch03-basic-strategy.html)*

<a id="chixuxiazhu"></a>
**持续下注（continuation bet）**　
翻牌前最后加注，翻牌后接着下注。

持续下注（continuation bet, cbet）指翻牌前示强、翻牌圈对手过牌后再次下注：翻牌出现两张 人头牌时，翻牌前加注者很可能至少击中顶对，对手很难反抗。2/3 底池的持续下注盈亏平衡所需 成功率只有 40%。统计时必须区分“河牌下注”与“河牌 cbet”，否则是在错误数据上推理。

*首次讲解：[L2 分析技术](ch02-analysis.html)*


## D

<a id="dichi"></a>
**底池（pot）**　
一局牌中各轮下注累积的筹码总额。

底池是决策的参照基准：底池赔率衡量跟注额与跟注后底池大小的关系；底池大小的诈唬下注需要 50% 的成功率才能保本，向下近似线性缩放。成牌下注应在底池的一半到 2/3 左右，用以惩罚 追牌。

*首次讲解：[L3 基本策略](ch03-basic-strategy.html)*

<a id="dichipeilv"></a>
**底池赔率（pot odds）**　
跟注额与跟注后底池大小的关系，决定跟注是否 +EV。

当 Win% > CallAmt / (Pot + BetAmt + CallAmt) 时跟注为 +EV，即你的跟注占新底池的百分比 不超过胜率就能盈利。实战中不用解方程：知道自己的命中率后，最多可以贡献新底池的那个百分比。 底池赔率的解是“能不能跟”或“最多跟多少”。

*首次讲解：[L3 基本策略](ch03-basic-strategy.html)*

<a id="dulichoumamoxing"></a>
**独立筹码模型（Independent Chip Model (ICM)）**　
把锦标赛筹码折算成奖池真实货币权益的模型。

独立筹码模型（ICM）把锦标赛筹码折算成奖池的真实货币权益：你的最后一颗筹码远比第一颗值钱， 因为出局就一无所获。泡沫期里生存权的价值可以压倒底池赔率——即使手持 KK，面对两家全下也 可能是明确的弃牌。

*首次讲解：[L2 分析技术](ch02-analysis.html)*

<a id="ersifaze"></a>
**二四法则（rule of 2 and 4）**　
每个补牌每张牌约值 2%、能看两张牌约值 4% 的胜率速算。

Phil Gordon 提出的速算法则：每多能看一张牌，每个补牌约值 2% 的胜率；如果能同时看到转牌 和河牌（例如对手已全下），每个补牌按 4% 计。精确计算与乘 2 的结果非常接近：同花听牌 9 个 补牌约 18%，卡顺听牌 4 个补牌约 8%。

*首次讲解：[L3 基本策略](ch03-basic-strategy.html)*


## F

<a id="fifty50"></a>
**Fifty50（Fifty50）**　
10 人赛前 5 名入圈，返还买入后按剩余筹码分另一半奖池。

Fifty50 锦标赛 10 人参赛、前 5 名进入钱圈，入圈即返还买入（\\$10），另一半奖池按剩余筹码 比例分配。分析其泡沫期决策需要 ICM：默认“平均玩家”模型给出跟注，按对手的紧范围修正后 结论翻转为弃牌。

*首次讲解：[L2 分析技术](ch02-analysis.html)*

<a id="fanpai"></a>
**翻牌（flop）**　
前三张公共牌，翻牌圈最常见的局面是弱成牌对听牌。

翻牌（flop）是前三张公共牌。盲注能以折扣价看到翻牌；翻牌圈上一人有一对或两对、另一人只有 顺子或同花听牌，是最常见的局面。中筹码（M > 10）时翻牌前是进攻方，翻牌就应该用 2/3 底池 持续下注。

*首次讲解：[L3 基本策略](ch03-basic-strategy.html)*

<a id="fanshishihouhui"></a>
**反事实后悔（counterfactual regret (CFR)）**　
在每位玩家信息集树的决策节点上分别做后悔匹配的求解算法。

CFR 从每位玩家的信息集构建“个人树”，在每个决策节点分别做后悔匹配；加权方式假设玩家“自己 一路打到了该节点”，故称反事实。收敛只要求使用收益的无偏样本，实际打出一手牌就完成一次 迭代，使大规模博弈可解。CFR+ 再把后悔下限截断在 0，并用穷举式搜索代替蒙特卡洛采样。

*首次讲解：[L7 博弈论](ch07-game-theory.html)*

<a id="fanwei"></a>
**范围（range）**　
一手牌的集合，分析对手与制定打法的基本语言。

范围（range）是一手牌的集合，同花性用 o（不同花）或 s（同花）表示，记法用系列中最低的牌 表示，如 QQ+。范围有两个用途：分析对手（估计持牌分布后计算我们的胜率）和决定我们的打法 （如“用 AT+、88+ 全下，其余弃牌”）。若一个范围是最优的，则该范围内每一手牌单独都是 +EV 的。

*首次讲解：[L4 翻牌前分析](ch04-preflop.html)*

## H

<a id="hepai"></a>
**河牌（river）**　
第五张也是最后一张公共牌。

河牌（river）是最后一张公共牌。松弱对手有牌时放任你便宜地看听牌，让你到河牌再决定自己 有没有牌。河牌统计必须与局面匹配：整体河牌下注频率不等于河牌持续下注频率，用前者推断 牌力是在错误的数据上做推理。

## J

<a id="jiazhixiazhu"></a>
**价值下注（value bet）**　
拿真牌下注以从更弱的牌身上榨取筹码。

对付跟注站的价值来自价值下注（value bet），诈唬则是唯一可能输钱给他们的方式。M > 30 的 暗三条挖矿区里，应耐心等待怪兽牌、做成后猛烈地价值下注。在 A-K-Q 游戏的结构中，价值下注 区域与诈唬区域联动：价值下注越宽，需要搭配的诈唬就越多。

*首次讲解：[L3 基本策略](ch03-basic-strategy.html)*

<a id="jijinxishuaf"></a>
**激进系数（AF）（aggression factor (AF)）**　
下注加注相对跟注的比率。

AF（aggression factor）对应玩家风格四象限中“激进—被动”一轴；另一轴“松紧”对应 VPIP。 这正是线上分析能把“气质分类”落到数据的原因。

*首次讲解：[L1 扑克理论导论](ch01-intro.html)*

<a id="jinbiaosai"></a>
**锦标赛（tournament）**　
用买入换比赛筹码、按名次分奖池、盲注不断上涨的游戏形式。

锦标赛里只有比对手活得更久才能拿到奖金：一次固定买入、盲注级别不断上涨、只能选玩家池， 方差比现金局更高。最重要的概念是节奏——在不摊牌的情况下慢慢积累筹码、避免主动进入五五开， 把必须赢下的对决留到筹码更深时。

*首次讲解：[L5 锦标赛打法](ch05-tournament.html)*


## K

<a id="kailipanju"></a>
**凯利判据（Kelly criterion）**　
对数效用下按优势比例下注，最大化长期增长率。

若你的效用函数是对数型的，最大化长期效用增长率要求按优势比例下注：一赔一的偏硬币赌局中 有 60% 胜率时，最优下注比例 f* = 0.6 − 0.4 = 0.2，即资金的 20%。它是二十一点算牌时下注 尺度的理论基础，也是上述资金管理经验法则的理论基础。

*首次讲解：[L5 锦标赛打法](ch05-tournament.html)*


## L

<a id="lagsongxiong"></a>
**LAG（松凶）（loose-aggressive (LAG)）**　
愿意看很多牌、跟注很多，不轻易放弃一手牌。

松凶（loose-aggressive）玩家有好牌当然下注，但愿意看很多牌、跟注很多。能否盈利取决于游戏 类型、对手和挑选时机的本事——确实有不少大赢家是 LAG。

*首次讲解：[L1 扑克理论导论](ch01-intro.html)*


## M

<a id="m"></a>
**M**　见 [M 比率](#mbilv)。

<a id="mbilv"></a>
**M 比率（M ratio）**　
有效筹码量与一圈盲注及前注成本之比。

M = 有效筹码量 ÷（大小盲注与前注之和），由 Paul Magriel 发明、Harrington 推广。两个等价 解读：每手都弃牌还能在被盲注耗光之前存活多少圈；以及筹码量相对于抢盲价值的倍数。M 还能 跨盲注级别归一化决策：筹码和盲注同乘 10 倍，决策本质相同。

*首次讲解：[L1 扑克理论导论](ch01-intro.html)*

<a id="majiao"></a>
**马脚（tell）**　
对手泄露信息的肢体线索，噪声海洋里的微弱信号。

扑克桌上的马脚（tell）或许对弱手有点用，但不足以作为职业本钱：实验中 FBI 审讯官判断是否 说谎的正确率接近随机（约 53%），只是比普通人自信得多——自我评估偏差让人高估自己的阅读。 任何时刻你试图揣测对手的策略，她都可以反过来揣测你。

*首次讲解：[L8 决策制定](ch08-decisions.html)*

<a id="mangzhu"></a>
**盲注（blinds）**　
小盲与大盲被迫投入的强制下注，是驱动翻牌前决策的根本力量。

小盲（SB）和大盲（BB）构成盲注组。盲注位已被迫投入筹码，能以折扣价看到翻牌，但翻牌后 每一轮都最先行动，信息劣势最大。任何人打一手牌的唯一理由就是有人想赢走盲注，盲注占筹码 的比例直接决定它的重要性。

*首次讲解：[L3 基本策略](ch03-basic-strategy.html)*


## N

<a id="nashenjunheng"></a>
**纳什均衡（Nash equilibrium）**　
没有任何玩家能通过单方面改变策略而获益的策略组合。

纳什均衡是一组策略：每位玩家各取一个策略，且没有任何玩家能通过单方面改变自己的策略而获益。 石头剪刀布的均衡是各以 1/3 的概率出三种手势——这个均衡的意义在于无人能剥削你，而不在于 期望最高。

*首次讲解：[L7 博弈论](ch07-game-theory.html)*


## P

<a id="pfr"></a>
**PFR（PFR）**　
翻前加注频率，与 VPIP 联读勾勒对手类型。

HUD 上 VPIP 65、PFR 45 说明对手又松又凶；73 手样本中 VPIP 11、PFR 1 的玩家在此之前总共 只加注过一次，画像为超紧——面对他的短筹码全下，其范围推断应从很紧的基线出发。

*首次讲解：[L2 分析技术](ch02-analysis.html)*

<a id="paomoqi"></a>
**泡沫期（bubble）**　
距钱圈约 10% 人数的阶段，业余玩家犯最大错误的时段。

泡沫期（bubble）大致在距钱圈还有约 10% 人数时开始，此时普通业余玩家明显打得太紧，宁可 放弃微小的夺冠期望也不冒出局风险。你在泡沫期的表现基本决定了你能走多远：善于利用的好玩家 在此阶段筹码翻倍的机会远超 50%。其元游戏有传统的被动型和近年过度激进型两种形态。

*首次讲解：[L5 锦标赛打法](ch05-tournament.html)*


## Q

<a id="qbilv"></a>
**Q 比率（Q ratio）**　
你的筹码量与全场平均筹码量之比，衡量锦标赛中的相对位置。

Q = 你的筹码量 ÷ 全场平均筹码量。Q 为 5 时无需激进，Q 为 0.2 时则意味着离钱圈还很远、 有大量追赶要做。它由 Harrington 提出但从未流行开来。

*首次讲解：[L1 扑克理论导论](ch01-intro.html)*

<a id="qianzhu"></a>
**前注（ante）**　
所有玩家在发牌前投入的小额强制注，计入一圈强制下注成本。

前注（ante）与大小盲一起构成 M 比率分母中的“一圈盲注与前注之和”。“多少个大盲”的报法 完全忽略前注：盲注 50/100 再加 25 的前注时，实际筹码压力几乎翻倍，“大盲数”却毫无变化。

*首次讲解：[L1 扑克理论导论](ch01-intro.html)*

<a id="qipaiquanyi"></a>
**弃牌权益（fold equity）**　
对手弃牌的可能性为下注方带来的价值。

弃牌权益（fold equity）是假设被跟注会输时，“对手弃牌的可能性”带来的价值：纯诈唬时 FE = Pot × Fold% − Bet × (1 − Fold%)。主动下注时你拥有弃牌权益带来的全部权益，跟注时 则没有。死亡区（M < 2）里你几乎没有弃牌权益——大盲有赔率跟注你的任何全下。

*首次讲解：[L3 基本策略](ch03-basic-strategy.html)*

<a id="qiwangzhi"></a>
**期望值（expected value (EV)）**　
所有可能结果的概率加权平均，本课程一切决策规则的基础。

期望值 EV = Win% × WinAmt − Lose% × LoseAmt，保本点在 EV = 0 处。与其问“该不该跟注”， 不如问“最多能跟多大的注”，令 EV = 0 求解阈值。扑克的优势正是由一个个边际决策累积而成， 即使两个选项的期望只差零点几个百分点也值得细算。

*首次讲解：[L3 基本策略](ch03-basic-strategy.html)*

<a id="quanxia"></a>
**全下（all-in）**　
把全部剩余筹码一次性投入底池。

全下（all-in）即投入全部筹码。筹码较浅时，你实际上是在用整个起手牌范围做“全下或弃牌”的 决策。M < 10 时基本只有全下或弃牌两种选择，因为加注会让对手获得再加注的空间、使你损失 弃牌权益，直接全下才能最大化弃牌权益。

*首次讲解：[L1 扑克理论导论](ch01-intro.html)*

<a id="quekoulilun"></a>
**缺口理论（gap theory）**　
跟注全下需要的牌力远强于主动全下。

Sklansky 的缺口理论（Gap Theory）：主动下注时你拥有弃牌权益带来的全部权益，跟注时则没有， 因此很多场合你可以用任意两张牌全下，却只有好牌才能跟注。

*首次讲解：[L5 锦标赛打法](ch05-tournament.html)*

## S

<a id="shootout"></a>
**Shootout（Shootout）**　
每张桌先各自打到只剩一人的淘汰赛制。

Shootout（淘汰赛制）的结构如 WSOP \\$3000 赛事：40 张 10 人桌各自打到只剩 1 人，然后由 Day 1 的 40 名胜者在 Day 2 重新组桌。案例 2 即在此赛制的单挑阶段应用全下/弃牌策略与 Sklansky-Karlson 模型。

*首次讲解：[Case 2](cases/case2.html)*

<a id="sklanskykarlsonpaiming"></a>
**Sklansky-Karlson 排名（Sklansky-Karlson ranking）**　
按两人对局翻牌前领先可能性排列的起手牌百分位排名。

最常用的起手牌百分位排名，依据两人对局中翻牌前领先的可能性：前 10 依次是 AA, KK, AKs, QQ, AKo, JJ, AQs, TT, AQo, 99。它来自 Sklansky 的“亮牌全下”问题——筹码不超过多少 x 时 亮开手牌全下仍是 +EV，由 Chubukov 对全部手牌求解得出排序。百分位与范围对应：前 5% 是 TT+、AQ+，前 30% 是 22+、A2+、Broadway。

*首次讲解：[L4 翻牌前分析](ch04-preflop.html)*

<a id="shangtou"></a>
**上头（tilt）**　
情绪失控导致打法变形的心理状态。

恐惧与上头（tilt）的典型表现：被迫亮出烂牌、输钱、赢的时候打短局而输的时候打长局。玩家 输得最多的时候往往是刚输掉超出计划的金额之后（痛苦阈值）。稳定心态的技术包括把资金按市值 记账，以及不想连胜连败、只想着盈亏平衡期。

*首次讲解：[L5 锦标赛打法](ch05-tournament.html)*

<a id="siweicengji"></a>
**思维层级（levels of thinking）**　
从“我有什么牌”到“他认为我在扮演什么”的读牌层级。

L0 不读牌，L1“我有什么牌”，L2“他有什么牌”，L3“他认为我有什么牌”，依此类推。你的目标是 恰好比对手高一个层级，而不是越高越好——对手根本不在读你时，在 L3 思考“扮演”就是层级错配。 合理的默认假设：新玩家在 L1，普通锦标赛玩家在 L2，现金局玩家在 L3。

*首次讲解：[L5 锦标赛打法](ch05-tournament.html)*


## T

<a id="tagjinxiong"></a>
**TAG（紧凶）（tight-aggressive (TAG)）**　
有好牌就下注，没好牌就弃牌；盈利最多的象限。

紧凶（tight-aggressive）被称为稳健 ABC（solid ABC）打法，是整体上盈利最多的象限，也是 本课程推荐的打法。Dan Harrington 是公认的紧凶型稳健玩家。

*首次讲解：[L1 扑克理论导论](ch01-intro.html)*

<a id="tpyulpjinruoyusongruo"></a>
**TP 与 LP（紧弱与松弱）（tight-passive and loose-passive (TP & LP)）**　
两个输钱象限：岩石式的紧弱与跟注站式的松弱。

TP（紧弱，也称岩石）没牌就弃、有牌也只是过牌，可以被完全碾压，一般认为明显次优。LP（松弱， “跟注站”）你有牌时他跟注你的每一次下注，他有牌时却放任你便宜地看听牌；在现实的样本量下 这一象限几乎不可能有人盈利，他们是牌桌上最大的输家。

*首次讲解：[L1 扑克理论导论](ch01-intro.html)*

<a id="tanpai"></a>
**摊牌（showdown）**　
下注轮结束后亮牌比大小，决定底池归属。

摊牌（showdown）是仍留在局中的玩家亮牌比较牌力的时刻。锦标赛中双方都不想打摊牌拼命时， 前位玩家可以率先全下来吓退对手。只有打到摊牌的手牌，才能在 PokerTracker 中看到对手的 底牌。

*首次讲解：[L3 基本策略](ch03-basic-strategy.html)*

<a id="tingpai"></a>
**听牌（draw (drawing hand)）**　
尚未成型、需要补牌才能获胜的牌。

听牌方要权衡击中听牌的概率与每多看一张牌的成本。不要听一手击中也未必赢的牌：Q 高或更小 的同花可能被更大的同花压制，顺子的低端极危险，在对子牌面上听同花或顺子甚至可能是在听 死牌（胜率为 0）。

*首次讲解：[L3 基本策略](ch03-basic-strategy.html)*

<a id="toumang"></a>
**偷盲（steal）**　
主动用加注直接抢下盲注与前注。

偷盲（steal）是主动抢盲注，反偷（re-steal）是识别出某人在偷盲后对他再加注反击。2 < M < 8 的偷盲期里唯一的动作是全下或弃牌，每偷到一次盲注筹码量就增加约 10%–40%。具体做法是找出 不保卫盲注的玩家专偷他们，同时对外装成会保卫盲注的人。

*首次讲解：[L5 锦标赛打法](ch05-tournament.html)*

<a id="touzihuibaolv"></a>
**投资回报率（return on investment (ROI)）**　
总回报除以投入再减一，锦标赛的核心效率指标。

ROI ＝ 总回报 ÷ 投入 − 1，例如投入 100k、收回 150k 即 ROI 50%。多桌锦标赛的优秀水准约 30%，单桌锦标赛约 15%。通常应最大化 ROI，直到它低到触及你设定的时薪下限；补充 ROI 的常用 手段是降级打更低注额。

*首次讲解：[L1 扑克理论导论](ch01-intro.html)*


## V

<a id="vpip"></a>
**VPIP（VPIP (voluntarily put money in pot)）**　
翻前主动投钱入池的手牌占比，刻画玩家卷入底池的程度。

VPIP（主动入池率）收敛很快——几乎每手牌都有一次观察机会；VPIP 40 的玩家打法风格大体 相似，可据此快速归类对手。它与 RFI 联读更有信息量：VPIP 70、RFI 2 的玩家“只跟不加”。

*首次讲解：[L1 扑克理论导论](ch01-intro.html)*


## W

<a id="weixingsai"></a>
**卫星赛（satellite）**　
前若干名赢得大赛门票的比赛，ICM 威力最大的赛制。

卫星赛（satellite）特别容易让人犯巨大的错误：10 人争 9 张门票时，KK 对任意两张牌的跟注 cEV 大赚而 \\$EV 大亏，连 AA 只要不是约 90% 以上的热门也应该弃牌。若所有人都理性，每个人的 跟注范围都是 0%，轮到行动就该用任意两张牌全下，直到盲注强行把某人套入为止。

*首次讲解：[L5 锦标赛打法](ch05-tournament.html)*

<a id="weizhi"></a>
**位置（position）**　
牌桌上的座位分组，决定行动顺序与信息多少。

牌桌上的位置分为盲注、前位、中位和后位四组。后行动的人在行动前能看到先行动者的选择， 掌握更多信息，因此位置越靠后可玩的起手牌范围越宽，盈利总体流向后位。短筹码（低 M）时 前位反而有优势：先行动者可以抢先全下，保住进攻带来的弃牌权益。

*首次讲解：[L3 基本策略](ch03-basic-strategy.html)*


## Y

<a id="yinhanpeilv"></a>
**隐含赔率（implied odds）**　
击中听牌后还需要再赢多少筹码，才能让眼前的跟注成立。

方法：求出底池要多大才能使当前跟注额恰好等于底池的 x%（你的胜率），再减去跟注后实际的 底池，差额就是需要补进去的死钱。死钱需求是否现实靠对牌局隐蔽性的判断：暗三条几乎读不出 来、隐含赔率极大，同花最明显、隐含赔率很小。

*首次讲解：[L3 基本策略](ch03-basic-strategy.html)*

<a id="youxiaochoumaliang"></a>
**有效筹码量（effective stack）**　
你在这一手牌里最多可能输掉的筹码数。

有效筹码量 = min（你的筹码量，仍在牌局中的最大筹码量）。行动何时结束由筹码更少的一方决定， 因此决策永远基于有效筹码量而非名义筹码量：即使你有 1500 而对手只有 300，对手一加注就意味 着全下，你就当自己只有 300。

*首次讲解：[L1 扑克理论导论](ch01-intro.html)*

<a id="yueduzijideshoupairyoh"></a>
**阅读自己的手牌（RYOH）（reading your own hand (RYOH)）**　
知道自己处于自身分布的哪个位置并塑造平衡，最重要的扑克技能。

RYOH 要求在每条街对自己的分布做两次更新：牌面排除（新公共牌修正组合数）与行动更新（删掉 不会采取该动作的牌），并检查价值与诈唬的比例是否平衡。经验法则：如果一手牌你本会拿它做 价值下注，你就该把分布塑造成不必弃掉它的样子。

*首次讲解：[L8 决策制定](ch08-decisions.html)*


## Z

<a id="zeebodingli"></a>
**Zeebo 定理（Zeebo's theorem）**　
没有任何玩家能够在任何下注轮弃掉葫芦，无论下注多大。

因此当对手可能有葫芦时，不要用更小的牌诈唬；反过来，你拿葫芦时就应当假定对手不会弃牌， 放手收取价值。

*首次讲解：[L5 锦标赛打法](ch05-tournament.html)*

<a id="zhahu"></a>
**诈唬（bluff）**　
因弃牌权益大于 0 而为 +EV 的下注。

诈唬（bluffing）是因为弃牌权益大于 0 而为 +EV 的下注，其保本弃牌率 = 下注/（底池+下注）。 诈唬下注要像拿真牌一样下，不要太小也不要超池；不要害怕被抓或亮出烂牌，诈唬时你拿什么牌 完全无关紧要；不要诈唬跟注站，诈唬是唯一可能输钱给他们的方式。

*首次讲解：[L3 基本策略](ch03-basic-strategy.html)*

<a id="zhuanpai"></a>
**转牌（turn）**　
第四张公共牌；不要假设一次下注能同时看到转牌和河牌。

转牌（turn）是第四张公共牌。除非进攻方已经全下，不要假设一次下注能看到转牌和河牌两张牌 ——很多玩家在翻牌圈跟注就是打着“便宜看两张”的主意，结果假设落空、白白损失 EV。到转牌时 底池通常已有约 10M，往往只剩全下或弃牌的决定。

*首次讲解：[L3 基本策略](ch03-basic-strategy.html)*

<a id="zijinguanli"></a>
**资金管理（bankroll management）**　
按 2% 破产风险为扑克资金规定买入数的规则体系。

资金（bankroll）是“一旦输掉你就认为不可挽回、并迫使你停止打牌”的那笔钱，概念只对盈利 玩家有意义。经验法则基于 2% 的破产风险：NL 现金局 20 个最大买入、限注 300 个大注、STT 30 个买入、MTT 50–100 个买入；且应随盈亏升降 stakes——输了降注会让破产率渐近趋零。 高方差赛事可用赞助和出售份额分散风险。

*首次讲解：[L5 锦标赛打法](ch05-tournament.html)*
